# E2E Test Fixtures

## `sample.wav`

A short spoken utterance used by the end-to-end ASR tests.

**Required format:**

| Property     | Value              |
|--------------|--------------------|
| Container    | WAV (RIFF)         |
| Sample rate  | 16 000 Hz          |
| Channels     | 1 (mono)           |
| Sample width | 16-bit signed PCM  |

**Expected transcript:** `the sky is blue`

The file is produced once with an online TTS tool and committed to the
repository. It is **not** generated by the test suite.
